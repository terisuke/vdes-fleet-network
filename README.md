# VDES Fleet Monitor - 漁船団ネットワーク監視システム

![VDES Fleet Network](https://github.com/user-attachments/assets/0aa67016-6eaf-458a-adb2-6e31a0763ed6)

## 📌 概要

**VDES Fleet Monitor** は、VHF Data Exchange System (VDES) 技術を活用した漁船団のリアルタイム監視システムです。複数の漁船の位置情報と魚群探知機データを統合し、地図上で視覚的に表示します。

### 主な機能

- 🗺️ **リアルタイム船団位置表示** - 自船および僚船の現在位置を地図上に表示
- 🐟 **魚群探知機モニター** - ソナーデータをリアルタイムで可視化
- 📊 **深度レイヤー別表示** - 表層・中層・底層の3レイヤーで魚群分布を確認
- 📜 **航跡履歴表示** - 過去の航跡と魚群検出ポイントを確認可能
- ⏱️ **更新間隔設定** - 10秒/30秒の更新頻度を選択可能

## 📖 詳細設計

### アプリケーション状態管理 (`App.tsx`)

アプリケーションは以下の状態を管理します：

| 状態              | 型                        | 説明                      |
|-------------------|---------------------------|---------------------------|
| `fleetData`       | `ShipEntity[]`            | 船団全体のデータ（履歴含む）     |
| `currentSimIndex` | `number`                  | 現在表示中のシミュレーションインデックス |
| `selectedLayer`   | `DepthLayer`              | 選択中の深度レイヤー           |
| `updateInterval`  | `10 \| 30`                | 更新間隔（秒）              |
| `inspectionState` | `InspectionState \| null` | 履歴検査モード状態           |

#### 主要な処理フロー

1. **初期化**: `generateFleetData()` でシミュレーションデータを生成
2. **シミュレーションループ**: 設定された間隔で `currentSimIndex` を自動更新
3. **履歴検査モード**: 航跡上のポイントをクリックすると履歴データを固定表示

---

### データ型定義 (`types.ts`)

#### `FishObject` - 魚群オブジェクト

```typescript
interface FishObject {
  dp: number;      // 深度開始位置（%）: 0=水面, 100=海底
  dw: number;      // 深度幅（%）: 反応の高さ
  lw?: number;     // 水平幅（オプション）
  type: FishType;  // 魚群タイプ: 'school' | 'medium' | 'large'
}
```

#### `TelemetryData` - テレメトリデータ

```typescript
interface TelemetryData {
  ts: number;         // タイムスタンプ（Unix epoch）
  lt: number;         // 緯度
  ln: number;         // 経度
  f: FishObject[];    // 検出された魚群配列
  sb: number;         // 海底深度（%）
}
```

#### `ShipEntity` - 船舶エンティティ

```typescript
interface ShipEntity {
  mmsi: string;            // 船舶識別番号
  name: string;            // 船名
  isSelf: boolean;         // 自船フラグ
  color: string;           // マーカー色
  history: TelemetryData[]; // テレメトリ履歴
}
```

#### `DepthLayer` - 深度レイヤー

```typescript
enum DepthLayer {
  Surface = 'surface',  // 表層: 0-30%
  Middle = 'middle',    // 中層: 30-60%
  Bottom = 'bottom'     // 底層: 60-100%
}
```

### コンポーネント詳細

#### `Header.tsx` - ヘッダー

アプリケーションのヘッダー部分を表示します。

**表示内容:**
- アプリ名（VDES Fleet Monitor）
- VDES接続ステータス（パルスアニメーション付きWifiアイコン）
- 自船情報（MMSI番号、船名）
- リアルタイム時計

---

#### `MapDisplay.tsx` - 地図表示

Leafletを使用した地図表示コンポーネントです。

**機能:**
- OpenStreetMapタイルによる地図表示
- 船舶位置のマーカー表示（カスタムボートアイコン）
- 航跡ライン表示（魚群検出箇所は赤色で強調）
- 魚群検出ポイントのサークルマーカー
- 履歴検査時のハイライトリング表示

**マーカースタイル（魚群タイプ別）:**

| タイプ      | 色             | 半径 | 説明      |
|----------|----------------|------|-----------|
| `school` | ピンク (#ec4899)  | 10px | 魚群（群れ） |
| `medium` | オレンジ (#f97316) | 6px  | 中型魚    |
| `large`  | シアン (#06b6d4)  | 3px  | 大型魚    |

**航跡表示ロジック:**
- 選択中の深度レイヤーに該当する魚群がある区間は赤色で表示
- 魚群なしの区間はグレーで表示

---

#### `Controls.tsx` - コントロールパネル

設定を行うコントロールパネルです。

**設定項目:**

1. **表示レイヤー選択**
   - 表層 (0-30%)
   - 中層 (30-60%)
   - 底層 (60-100%)

2. **更新頻度設定**
   - 10秒間隔
   - 30秒間隔

---

#### `FishFinder.tsx` - 魚群探知機モニター

ソナーデータを視覚的に表示するモニターです。

**表示要素:**
- ステータスバー（REAL-TIME / HISTORY表示）
- 深度グリッドライン
- 深度目盛り（0m〜100m）
- 魚群反応（タイプ別に色分け）
- 海底ライン
- レイヤー境界線（破線）

**魚群表示スタイル:**

| タイプ      | 色   | エフェクト          |
|----------|------|----------------|
| `school` | ピンク  | ぼかし強、発光効果 |
| `medium` | オレンジ | ぼかし中、発光効果 |
| `large`  | シアン  | シャープ、強い発光   |

**表示ウィンドウ:** 直近20スライスのデータを表示

### シミュレーションサービス (`simulationService.ts`)

デモ用のシミュレーションデータを生成します。

**設定パラメータ:**
- `SIMULATION_POINTS`: 60ポイント（約5分間のデータ）
- `INITIAL_CENTER`: 石垣島北部海域 (24.34, 124.15)

**航路設定:**
```typescript
const SAFE_WAYPOINTS = [
  { lat: 24.6000, lng: 124.1500 }, // 開始点
  { lat: 24.6200, lng: 124.2500 }, // 中間点
  { lat: 24.6100, lng: 124.3500 }, // 終了点
];
```

**船団構成:**
| 船名        | MMSI      | 役割  | マーカー色 |
|-------------|-----------|-------|--------|
| Host Maru   | 431000000 | 自船  | 青     |
| Ryojin Maru | 431000001 | 僚船1 | 緑     |
| Kaito Maru  | 431000002 | 僚船2 | オレンジ   |

**魚群生成ロジック:**
- 状態機械方式で連続性のある魚群データを生成
- 40%: 魚群なし
- 30%: 魚群（school）
- 20%: 中型魚（medium）
- 10%: 大型魚（large）

## 🖥️ UI/UX設計

### レスポンシブ対応

- **モバイル**: 縦並びレイアウト（地図50%、情報パネル50%）
- **デスクトップ** (lg以上): 12カラムグリッド（地図8列、情報パネル4列）

### 主要なインタラクション

1. **航跡クリック**: 該当時点の魚群データを詳細表示（履歴検査モード）
2. **「現在地へ (LIVE)」ボタン**: ライブモードに復帰
3. **レイヤー切替**: 地図上の航跡表示とフィルタリングを更新
4. **更新間隔変更**: シミュレーションの進行速度を変更

### 視覚的フィードバック

- **ライブモード**: 緑色のインジケーター、パルスアニメーション
- **履歴検査モード**: 琥珀色のインジケーター、ボタンバウンスアニメーション
- **選択中のポイント**: 白い破線リング（パルスアニメーション）
